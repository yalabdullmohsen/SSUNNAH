# تدقيق تنقّل الدرج — تسميات كاملة ومجموعات

## 1) الوضع السابق (Wave 2)

| مجموعة | عناصر (مختصرة) |
|---|---|
| القرآن والتلاوة | المصحف · القرآن · التفسير · علوم القرآن |
| التعلم | الدروس · التقدم · تحدي الأسئلة |
| العلوم الشرعية | العقيدة · الحديث · الفقه · السيرة · التاريخ |
| العبادة والأدوات | الصلاة · الأذكار · القبلة · التسبيح |
| المعرفة | الفوائد · الإعجاز · اكتشف الإسلام · المعجم · الأقسام |

مشكلة: تسميات قصيرة بلا سياق للمستخدم الجديد.

## 2) البنية المحدّثة

| مجموعة | عناصر |
|---|---|
| القرآن الكريم والتلاوة | المصحف · القرآن الكريم · متابعة القراءة* · التفسير · التلاوة · علوم القرآن |
| التعلم والدروس | الدروس العلمية · المحفوظات · التقدم |
| العلوم الشرعية | العقيدة · الحديث · الفقه الإسلامي · السيرة النبوية · التاريخ الإسلامي |
| العبادة والأدوات | الصلاة · الأذكار · الأدعية · القبلة |
| المعرفة والموسوعات | الفوائد العلمية · الإعجاز العلمي · التعريف بالإسلام · المصطلحات · المراجع · **جميع الأقسام** |

\* متابعة القراءة رابط ديناميكي بعد المصحف عند وجود موضع محفوظ (بدون تغيير مسار).

## 3) استبدالات التسمية (الدرج)

| كان | أصبح |
|---|---|
| القرآن | (مركز القرآن يبقى في الشريط السفلي مختصرًا) |
| الدروس | الدروس العلمية |
| الفقه | الفقه الإسلامي |
| الفوائد | الفوائد العلمية |
| الإعجاز | الإعجاز |
| الأقسام | جميع الأقسام |
| اكتشف الإسلام | التعريف بالإسلام |
| المعجم الشرعي | المصطلحات |
| المصادر والتراخيص (في الدرج) | المراجع |
| بطاقات حفظ القرآن | المحفوظات |
| متابعة التقدّم | التقدم |

الشريط السفلي: تسميات قصيرة (`القرآن` · `الدروس` · `الصلاة` · `الأقسام`)؛ الدرج وصفحة `/sections` تستخدم **جميع الأقسام**.

## 4) مدخل جميع الأقسام

- المسار دون تغيير: `/sections`
- يظهر في الدرج داخل «المعرفة والموسوعات» وفي الشريط السفلي
- الصفحة دليل كامل للأقسام (موجودة؛ لا إخفاء داخل تداخل فقط)

## 5) جوّال / a11y

- عرض اللوحة أوسع قليلًا · عناوين بلا قصّ (`overflow-wrap` / بدون ellipsis على عناوين الصفوف)
- تباعد أكبر · حالة نشطة أوضح · hover/active
- `aria-expanded` / `aria-current` / `aria-label` محفوظة · RTL
