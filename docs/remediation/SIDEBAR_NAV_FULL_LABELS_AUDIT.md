# تدقيق تنقّل الدرج — عنوان + توضيح

## 1) الوضع السابق (Wave 2)

| مجموعة | عناصر (مختصرة) |
|---|---|
| القرآن والتلاوة | المصحف · القرآن · التفسير · علوم القرآن |
| التعلم | الدروس · التقدم · تحدي الأسئلة |
| العلوم الشرعية | العقيدة · الحديث · الفقه · السيرة · التاريخ |
| العبادة والأدوات | الصلاة · الأذكار · القبلة · التسبيح |
| المعرفة | الفوائد · الإعجاز · اكتشف الإسلام · المعجم · الأقسام |

مشكلة: تسميات قصيرة بلا سياق، ثم جاءت تسميات طويلة في سطر واحد زادت تكلفة العرض وTBT على الرئيسية.

## 2) البنية المحدّثة (عنوان + توضيح)

| مجموعة | توضيح | عناصر |
|---|---|---|
| القرآن | المصحف • التفسير • التلاوة | المصحف · القرآن · التفسير · التلاوة · علوم القرآن · متابعة القراءة* |
| الدروس | الدروس والمحاضرات | الدروس · المحفوظات · التقدم |
| العلوم | عقيدة • حديث • فقه • سيرة | العقيدة · الحديث · الفقه · السيرة · التاريخ |
| العبادة | صلاة • أذكار • أدوات | الصلاة · الأذكار · الأدعية · القبلة |
| المعرفة | فوائد • إعجاز • مراجع | الفوائد · الإعجاز · التعريف · المصطلحات · المراجع · **جميع الأقسام** |

\* متابعة القراءة رابط ديناميكي بعد المصحف عند وجود موضع محفوظ (بدون تغيير مسار).

## 3) استبدالات التسمية (الدرج)

نمط العرض: **عنوان قصير** + **توضيح مختصر** (لا سطر تنقّل طويل واحد).

| كان (سطر طويل) | أصبح |
|---|---|
| القرآن الكريم والتلاوة | القرآن + المصحف • التفسير • التلاوة |
| الدروس العلمية | الدروس + الدروس والمحاضرات |
| الفقه الإسلامي | الفقه + الأحكام الفقهية |
| الفوائد العلمية | الفوائد + فوائد علمية مختارة |
| الإعجاز العلمي | الإعجاز + الإعجاز العلمي |
| الأقسام | **جميع الأقسام** (مقصد مخصّص) |

الشريط السفلي: تسميات قصيرة (`القرآن` · `الدروس` · `الصلاة` · `الأقسام`)؛ الدرج يحتفظ بـ **جميع الأقسام** كمقصد واضح.

`/flashcards` و`/ulum-quran` تظهران في الدرج عبر allowlist، وتبقيان خارج الاكتشاف العام (HIDDEN_FROM_NAV) حتى لا يزداد فهرس البحث على الرئيسية.

## 4) مدخل جميع الأقسام

- المسار دون تغيير: `/sections`
- يظهر في الدرج داخل «المعرفة» وفي الشريط السفلي (بتسمية مختصرة `الأقسام`)
- الصفحة دليل كامل للأقسام — لا يُحذف

## 5) أداء / جوّال / a11y

- لا تُرسم صفوف المجموعات المطوية (تقليل DOM/أيقونات Lucide)
- متابعة القراءة تُحمَّل فقط والدرج مفتوح
- عرض اللوحة أوسع قليلًا · عناوين بلا قصّ (`overflow-wrap`)
- `aria-expanded` / `aria-current` / `aria-label` محفوظة · RTL
