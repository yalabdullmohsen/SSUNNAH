# AUDIO_HEADERS_CHECK — فحص ترويسات طلبات الصوت على RC3

> إلى ن4. يثبت أن اتصالات التلاوة بـ**EveryAyah** و**MP3Quran** لا تحمل غير الترويسات القياسية، ليطابق الواقعُ فقرةَ مضيفي الصوت في `PRIVACY_CHECK.md` (القسم 1). **لم يُنفَّذ أي فحص بعد**؛ كل بند «لم يُتحقق» حتى يصل بناء RC3 ويُعلَّم ✔ بدليل. لا يُعدَّل كود Swift ضمن هذه الوثيقة.

## الإعداد
1. بناء RC3 مُثبَّت على جهاز حقيقي (iPhone)، وجلسة Proxy على الحاسوب (Charles أو mitmproxy أو Proxyman) على الشبكة نفسها، مع تثبيت شهادة الـProxy على الجهاز للقراءة داخل TLS. (الشهادة للفحص فقط ولا تُحفظ في المستودع.)
2. اختبر **مرتين**: (أ) وأنت **مسجّل الدخول** بحساب تجريبي، (ب) **بلا حساب**؛ لأن الخطر الوحيد هو تسرّب جلسة الحساب إلى المضيفين.
3. نظّف سجل الـProxy قبل كل سيناريو.

## السيناريوهات
| # | السيناريو | المتوقع في الشبكة | ✔/✘ + دليل |
|---|---|---|---|
| 1 | فتح التطبيق وتصفح المصحف وأقسام أخرى **دون** تشغيل صوت | صفر طلبات إلى `everyayah.com` و`mp3quran.net` وما يتبعهما | |
| 2 | تشغيل آية/سورة (بث) | الطلبات تذهب إلى المضيف المطلوب فقط، وبعد الضغط على التشغيل لا قبله | |
| 3 | تنزيل سورة للاستماع دون اتصال | الطلبات إلى المضيف المطلوب فقط، وبعد طلب التنزيل صراحةً | |
| 4 | تغيير القارئ ثم التشغيل | مضيف القارئ الجديد فقط؛ لا طلبات احتياطية صامتة لمضيف آخر | |
| 5 | إعادة التشغيل من الكاش بعد التنزيل (وضع الطيران) | صفر طلبات شبكة | |
| 6 | التطبيق في الخلفية والصوت يعمل | لا طلبات جديدة غير ما يلزم تدفق التشغيل | |

## ما يُفحص في كل طلب (لكل مضيف على حدة)
| الترويسة/الحقل | المتوقع | ✔/✘ + دليل |
|---|---|---|
| `User-Agent` | القيمة القياسية لـCFNetwork/AVFoundation (اسم التطبيق وإصدار النظام) دون معرّف مستخدم أو بريد | |
| `Authorization` | **غائبة** | |
| `Cookie` / `Set-Cookie` المُرسَل من التطبيق | **غائبة** (لا ملف تعريف مرسَل) | |
| `apikey` أو ترويسات Supabase (`x-client-info`…) | **غائبة** | |
| أي ترويسة مخصصة تبدأ بـ`X-` | **غائبة** | |
| معرّف المستخدم أو البريد أو الاسم أو الموقع داخل المسار أو الاستعلام (`?`) | **غائبة**؛ المسار ملف صوتي فقط (سورة/آية/قارئ) | |
| `Referer` / `Origin` | غائبة أو لا تحمل بيانات | |
| نوع الطلب | `GET` (وربما `HEAD`/`Range` للبث) فقط، بلا جسم (body) | |
| بروتوكول الاتصال | HTTPS (لا HTTP نصي) | |
