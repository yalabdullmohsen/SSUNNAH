# خطة لقطات المتجر (iPhone / iPad / Watch)

> قائمة مرتّبة بالشاشات؛ **تُلتقط عبر ن4 بعد استقرار الواجهة** (`ios-native/scripts/capture-store-screenshots.sh`، انظر SCREENSHOTS.md). عربي RTL، فاتح، بيانات حقيقية، بلا شريط تجريبي. لا نصوص تسويقية تنسب مراجعة لأحد. لا لقطة للموقع/الخريطة تكشف عنوانًا شخصيًا.

## iPhone 6.9" (1320×2868) — 6 لقطات بهذا الترتيب
1. الرئيسية (`majlisilm://`) — أول انطباع.
2. المصحف (`/mushaf`) — صفحة بالرسم العثماني.
3. المواقيت (`/prayer-times`) — مدينة معلنة (مثلًا مكة).
4. القبلة (`/qibla`).
5. الأذكار (`/adhkar`).
6. المكتبة (`/library`).
اختياري (حتى 10): 7) حاسبة الفرائض، 8) الوضع الداكن للمصحف، 9) ويدجت المواقيت على الشاشة الرئيسية.

## iPad 13" (2064×2752) — 4–6 لقطات
نفس ترتيب 1–6 بتخطيط iPad الفعلي (لا تمديد لقطة iPhone).

## Apple Watch — **لا تُلتقط ولا تُرفع حتى يؤكد ن4 نجاح رفع الساعة**
(إن أُكّد: شاشة المواقيت التالية ثم الإكمال؛ المقاس حسب أحدث طراز مطلوب في ASC.)
