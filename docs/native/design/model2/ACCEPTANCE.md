- [ ] كل الأرقام عربية-هندية (٠–٩): الأوقات، التواريخ، العدّادات، الترقيم.
- [ ] لا مظهر iOS افتراضي: لا List/Form insetGrouped، لا Toggle نظام، لا Picker مقسّم نظام، لا TabView نظام، لا شريط تنقل نظام.
- [ ] أهداف اللمس ≥ 44pt؛ الأزرار والشرائح دائرية بالكامل.
- [ ] الأيقونات داخل مربعات 38–40pt بزاوية 12–13، نعناعي #E6EFE9 أو ذهبي فاتح #F3EBD5.
