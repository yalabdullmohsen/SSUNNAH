# جرد شاشة الإعدادات (`/settings`)

الملف: `Special/SettingsScreens.swift` (`SettingsView`) + `Special/AppearancePrefs.swift` (`AppearanceOptionsView`).

## قبل
List واحدة بثلاثة أقسام:
- الحساب: البريد + «تسجيل الخروج»، أو «لم تسجّل الدخول» بلا زر دخول.
- المظهر: أيقونة التطبيق، السمة، خط التطبيق، حجم النص.
- الخصوصية: سطر نصي فقط (بلا رابط فعلي).

## الفجوات
- لا وصول إلى شاشات الإعدادات الأصلية الموجودة: التنبيهات، وضع المسجد، وضع السيارة، دون اتصال، مركز الودجت، مركز الخصوصية، الحذف، المصادر والتراخيص، سياسة الفتوى، عن التطبيق، تواصل معنا، جولة التطبيق.
- زر دخول غائب للزائر؛ نص الحذف بلا رابط.
- صفوف بلا أيقونات ولا تجميع منطقي.

## بعد
مجموعات: الحساب · المظهر · الصلاة والتنبيهات · البيانات والودجت · الخصوصية · عن التطبيق. كل صف يفتح مساره الحالي بـ`openRoute` (لا منطق جديد، المواقيت والجدولة عرض/تنقّل فقط).

## ديون
- لا لقطة SE/iPad/iOS16.
- خيارات بلا شاشة أصلية بعد: لغة، إعدادات الحساب المتقدمة.
