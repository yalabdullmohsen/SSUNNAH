## النص المقترح (العربية، حد ASC 4000 حرف)

مجالس السنة 1.2.0: واجهة أنقى وقراءة أريح.

• المصحف بالحجم الطبيعي كالمطبوع: سطور وزخرفة رقم الآية وتخطيط الصفحات أقرب للمصحف المرجع، مع شريط إجراءات للآية وفهرس ببطاقات.
• تفسير الآية صوتيًا: يبدأ فورًا بمقطع الآية وحدها، مع خيار «مكتوب/صوتي».
• الرئيسية والأقسام: شبكة اختصارات وبلاطات كبيرة بعناوينها، وآية اليوم وحديثه بخط الأميري.
• الحديث والفقه والسيرة: صفحات أوضح بمحاور وبطاقات، وفهرس قفز للقوائم الطويلة، وأداء أسرع لقوائم الحديث.
• الصلاة والأذكار والورد اليومي: إعادة تصميم كاملة.
• الحساب والإعدادات: بطاقات موحّدة وتباين أفضل.
• ألوان فاتحة هادئة: أخضر مريمي وبطاقات عاجية.
• دعم أحجام الخط الكبيرة (Dynamic Type) حتى AX3 دون تداخل.
• ألوان الودجات ونشاط Live Activity مطابقة لهوية التطبيق.
