# سكربت اختبار TestFlight — يوسف (10 دقائق)

الجهاز: iPhone حقيقي، آخر بناء TestFlight. جرّب فاتحًا ثم داكنًا (الخطوة 9). كل خطوة: ✅ سليم / ❌ خلل (أرسل ما في آخر الملف).

1. **الإقلاع (30ث):** أغلق التطبيق كليًا ثم افتحه. تظهر الرئيسية بلا وميض أو شاشة بيضاء.
2. **التصميم الجديد (النموذج ٢) — إن كان في البناء (1د):** الرئيسية بطاقة خضراء واحدة، شريط سفلي عائم بخمس تبويبات، أرقام عربية (٤:٣٢)، لا مظهر iOS افتراضي. مرّر على الصلاة والأقسام والأنبياء والأذكار والإعدادات.
3. **المصحف — الخط (1د):** افتح المصحف: الخط حادّ وأوضح بلا ظل مزدوج على الصفحات ١ و٢ و٢٥٠ و٦٠٤.
4. **المصحف — البحث (1د):** اضغط حقل البحث أعلى الصفحة، ابحث «الرحمن» → تظهر نتائج، اضغط نتيجة → تنتقل لموضعها.
5. **المصحف — الأدوات بالنقر (30ث):** الأدوات مخفية افتراضيًا؛ انقر الصفحة فتظهر، انقر ثانيةً فتختفي، والشريط السفلي لا يغطي الآية.
6. **العلامات الملوّنة الخمس — إن وُجدت (1د):** حدّد آية، اختر لونًا من الخمسة، أغلق وأعد الفتح: العلامة باقية بلونها؛ جرّب حذفها.
7. **قصص الأنبياء (1.5د):** الأقسام ← قصص الأنبياء ← افتح «آدم» ثم «موسى»: شرائح القفز تعمل، كل قسم تحته مصدره، وفي الأسفل الإفصاح وزر «أبلغ عن خطأ». اضغط الزر: يفتح نموذج البلاغ.
8. **الأذكار والصلاة (1د):** أذكار الصباح: العدّاد يعدّ ويتقدّم؛ الصلاة: خمس أوقات + القبلة تتحرك مع الجهاز؛ فعّل تنبيه صلاة واحدة.
9. **الداكن والإعدادات (1د):** الإعدادات ← المظهر ← داكن: كل الشاشات مقروءة؛ حجم الخط له معاينة؛ «عن التطبيق» فيه الإفصاح (محتوى بمساعدة الذكاء الاصطناعي).
10. **الودجتات (1د):** أضف ودجت «الضحى» أو «الأسماء الحسنى» للشاشة الرئيسية: يعرض بياناته ومصدره.

## عند الخطأ أرسل (للمنسّق)
- رقم الخطوة + ما حدث + ما توقعته (جملة).
- لقطة شاشة (أو تسجيل شاشة للتأخير/التعليق).
- رقم البناء (الإعدادات ← عن التطبيق) وموديل الجهاز ونسخة iOS.
- من TestFlight: «Send Beta Feedback» بعد لقطة الشاشة يرفق البيانات تلقائيًا.
- في حالة الانهيار: لا حاجة لشيء؛ تظهر تقاريره في TestFlight/Xcode Organizer.
