## ما يبقى عند يوسف
1. كلمة سرّ المراجِع في ASC.
2. فتح حساب Vercel المحجوب (فحوص Vercel تفشل «Account is blocked» على كل PR).
3. قرار توثيق مراجع الأنبياء (10.4% / 58.0% / 31.6%).
4. قرار «ابنِ النهائي» ثم رفع اللقطات والتقديم.
