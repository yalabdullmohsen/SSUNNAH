# قواعد الواجهة الأصلية (iOS)

- **لا تُغطّي بطاقة أو شريط أي عنصر محدد.** عند ظهور بطاقة سفلية (آية محددة…) لا يجوز أن يتقاطع مستطيل العنصر المحدد (كل أسطره) مع منطقة البطاقة: تُحسب الإزاحة من الارتفاع الفعلي للبطاقة (`SheetAvoidance`) فتُزاح الصفحة، أو تُنقل البطاقة للأعلى، أو تُصغَّر كحل أخير. تُغطّى الحالات: متعدد الأسطر، أول/آخر سطر، iPad، Dynamic Type.
- **شريط التبويب مخفي في كل شاشات المصحف** (أي مسار يبدأ بـ`/mushaf` والتفسير `/tafsir/`) بقاعدة واحدة `ReaderRoutes.hidesTabBar(path:)` يقرؤها `RootTabView`؛ لا إعلان فرديًا لكل شاشة.
- **زر الخروج في المصحف** يظهر بلمسة فراغ ويختفي بعد ثانيتين من آخر تفاعل (`ChromeAutoHide`)؛ ثابت مع البطاقة المفتوحة ومع VoiceOver، بلا حركة مع Reduce Motion.
