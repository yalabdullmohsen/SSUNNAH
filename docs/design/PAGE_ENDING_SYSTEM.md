# Page Ending System — سُنّة (Closure Wave B)

Utility: `.sf2-page-end` (+ `__nav`, `__meta`) in `sunnah-foundation-v2.css`.

## Patterns

### Scientific / article

1. references · 2. related · 3. report error · 4. save/share · 5. previous/next · 6. safe inset via `--content-pb`

### Lessons detail

related lessons · organizer · calendar/save · share · safe inset

### Directory / list

related directory or load-more / end-of-results · one useful next action · safe inset

## Rules

- No decorative mobile mega-footers.
- Do not duplicate bottom navigation inside content.
- No final card under the nav — rely on `#main-content` `--content-pb`.
- Prefer compact, semantic actions.
