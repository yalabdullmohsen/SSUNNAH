# إعادة تصميم الرئيسية — سُنّة

تاريخ: 2026-09-27 · فرع: `cursor/homepage-redesign`

## 1) تدقيق (قبل)

| مشكلة | أثر |
| --- | --- |
| بطاقات أقسام عملاقة (قرآن / دروس / صلاة / فقه / أذكار) + زر «افتح» | كثافة منخفضة، تمرير طويل، CTA متنافسة |
| كتل مكررة (مقدّس اليوم + ورد + بوابات) | تكرار محتوى يومي وضعف هرمية |
| هيرو بأسلوب لوحة تحكم | أولوية ضعيفة للتعلّم |
| زيارات أخيرة بصناديق فارغة | قيمة منخفضة / ضوضاء بصرية |
| بطاقة «ابدأ من هنا» بشبكة خطوات | تستهلك الشاشة الأولى |
| زر «إلى الأعلى» ظاهر مبكرًا | إزعاج بصري |
| خلفيات شبكية / أنماط زخرفية | مظهر ثقيل غير premium |

## 2) المكوّنات الجديدة

| مكوّن | دور |
| --- | --- |
| `HomeContinueLearning` | أولوية عليا — استئناف محلي + CTA واحد |
| `HomeDailyStrip` | آية / حديث / ذكر / فائدة — شبكة مضغوطة موحّدة |
| `HomeSectionsGrid` | أقسام رئيسية عمودان · البطاقة كلها قابلة للنقر |
| `HomeRecommended` | مقترحات من سجل القراءة/الزيارات (بلا اختراع) |
| `HomeRecentPagesBar` (محدّث) | شريط أفقي؛ يُخفى إن لم توجد زيارات |
| CSS: `home-continue-learning` / `home-daily-strip` / `home-sections-grid` / `home-recommended` / `home-recent-rail` | أسطح نظيفة · ظل خفيف · نصف قطر موحّد |

## 3) المُزال / المُستبدل من مسار الرئيسية

- بطاقات `SunnahCardV2` العملاقة من `HomeBelowFold` / الاكتشاف الأساسي
- مسار `HomeSacredOfDay` + `HomeDailyWird` كبوابات فوق الطية (أُبقي الهيكل للتوافق مع CLS فقط حيث يلزم)
- شبكة خطوات `hsh-steps` من بطاقة الزائر (`HomeStartHereSection` → `--slim`)
- ظهور مبكر لـ `ScrollToTop` (عتبة ≥ 720px أو 0.85vh)

ما المُبقى خارج مسار الاكتشاف (للمهام الأخرى / أسفل الطية): دروس، تقدّم يومي، ويدجات اختيارية، تخصيص الصفحة.

## 4) الهيكل الجديد (فوق → تحت)

1. بحث موحّد (`HomeUniversalSearch`) — فوري خارج Suspense
2. هوية مضغوطة (`HomeHeroLcp` — CTA واحد بلا شريط إجراءات سريعة)
3. ابدأ من هنا (`HomeStartHereSection` — نحيف)
4. متابعة التعلّم (`HomeContinueLearning`)
5. محتوى اليوم (`HomeDailyStrip`)
6. الأقسام الرئيسية (`HomeSectionsGrid` — عمودان)
7. محتوى أساسي (`HomeContentHub`)
8. بث مباشر (مؤجّل)
9. نشاط أخير + مقترح لك + دروس / ويدجات (تحت الطية)

ترتيب الصدفة LCP (`HomeRestShell`): اكتشاف أساسي → مباشر → تحت الطية (البحث فوقها ثابت).

## 6) أثر الأداء

| مقياس | اتجاه متوقع |
| --- | --- |
| طول الصفحة الرأسي فوق الطية | ↓ (بطاقات أقصر · بلا خطوات عملاقة) |
| عدد بطاقات الأقسام العملاقة فوق الطية | ↓ إلى شبكة 2×N مضغوطة |
| تعقيد التخطيط (طبقات زخرفية / بوابات مكررة) | ↓ |
| LCP/CLS | محمي بصدفات `HomeRestShell` + حجز CSS حرج محدّث (`--slim` / daily strip) |
| TBT | لا زيادة مسار عمل ثقيل جديد؛ الاكتشاف الأساسي مؤجّل ~280ms |

## 7) مراجعة الوصول

- اتجاه RTL محفوظ على المكوّنات الجديدة
- عناوين أقسام `h2` + `aria-label` / `aria-labelledby`
- بطاقات الأقسام واليومي روابط كاملة (لا زر منفصل يضعف الهدف)
- تباين أخضر/حبر على خلفية فاتحة ضمن هوية سُنّة (AA مستهدف)
- احترام `prefers-reduced-motion` عبر طبقة الصقل القائمة
- تحجيم نص ديناميكي: أحجام `rem` و`clamp` حيث ينطبق؛ بلا تثبيت بكسل مطلق للنصوص الأساسية

## 8) بوابات محدّثة

- `ssunnah-anti-legacy-ui-gate` — شبكة أقسام + يومي + متابعة؛ بلا `SunnahCardV2` في below-fold
- `cls-home-gate` / `lcp-critical-shell-gate` — حجز `--slim` / daily
- `visual-redesign-v2-tokens-gate` / `ssunnah-design-system-gate` — توافق الهيكل
- `dark-mode-recovery-gate` — بطاقة زائر نحيفة بلا `hsh-steps`
- `ScrollToTop` — عتبة تمرير ملحوظة
