# إعادة تصميم تجربة الدروس — سُنّة

تاريخ: 2026-09-27 · فرع: `cursor/lessons-experience-redesign`

## 1) تدقيق UX (قبل)

| مشكلة | أثر |
| --- | --- |
| بطاقات طويلة + وصف + شبكة meta | مسح بطيء · دروس قليلة فوق الطية |
| أزرار متعددة ظاهرة (تفاصيل/تقويم/بث/موقع/تسجيل) | ضوضاء قرار |
| فلاتر حبوب ثقيلة بلا «هذا الأسبوع» ظاهر | اكتشاف ضعيف |
| صفحة تفصيل بشكل نموذج (شبكة حقول + خريطة iframe كبيرة) | إحساس إداري لا تعليمي |
| ضعف تمييز أنواع المحتوى | كل البطاقات متشابهة |

## 2) هندسة المعلومات

**القائمة:** بحث/فلتر لاصق → شبكة بطاقات كثيفة (عنوان · محاضر · مكان · موعد) → المزيد.

**التفصيل:**
1. Hero (عنوان + نوع)
2. المحاضر
3. الموعد
4. نوع الحضور + المكان
5. إجراءات سريعة
6. الوصف
7. خريطة مضغوطة (تتوسع عند الطلب)
8. ذات صلة: نفس المحاضر / نفس التصنيف / نفس السلسلة
9. تفاصيل إضافية (disclosure)

## 3) نظام البطاقة

- `lesson-unified-card--dense` + `data-lesson-type`
- أولوية: عنوان → شيخ → مكان/موعد
- أساسي: «التفاصيل»
- ثانوي: حفظ + قائمة overflow (تقويم / بث / موقع / تسجيل)
- أنواع: قرآن · تفسير · حديث · عقيدة · فقه · سيرة · عام (لمسات لونية هادئة)

## 4) التفصيل

- ترتيب المحتوى حسب الأولوية التعليمية
- خريطة معاينة → iframe عند التوسيع فقط
- بيانات إدارية خلف «تفاصيل إضافية»

## 6) الوصول

- RTL محفوظ
- أهداف لمس ≥40–44px على الأزرار/الفلاتر
- `aria-expanded` / `aria-haspopup` لقائمة overflow والخريطة
- تباين أخضر/حبر على أسطح فاتحة؛ قواعد داكنة للقائمة/الخريطة

## 7) الأداء

| أثر | اتجاه |
| --- | --- |
| ارتفاع البطاقة | ↓ → دروس أكثر فوق الطية |
| iframe خريطة عند التحميل | ↓ (يُحمَّل بعد التوسيع) |
| أزرار DOM الظاهرة | ↓ عبر overflow |
| تعقيد CSS | +طفيف لأنواع الدروس |
