# صوت تنبيهات الصلاة (بدل الأذان)

قرار المالك: لا أذان ولا ملفات أذان في التطبيق نهائيًا. بدلها تنبيه صوتي قصير بعبارة فقط، بصوت ذكاء اصطناعي عربي هادئ بلا موسيقى.

## الحالة: **معلّق — لم تُولَّد المقاطع**
المقاطع العشرة عناصر نائبة بالأسماء فقط. الإشعار يرجع لصوت iOS النظامي حتى يوجد الملف فعلًا في الحزمة
(`NotificationSoundPack.sound(named:)` يتحقق من وجوده؛ لا ملفات صامتة تُسكت الإشعار).

## لماذا تعذّر التوليد
- لا محرك TTS محلي على الجهاز (لا piper ولا espeak-ng ولا ffmpeg)، وأصوات macOS (`say`) ممنوعة بقرار المالك.
- لم أجد محركًا بترخيص تجاري **موثَّقًا قابلًا للتحقق**:
  - Piper `ar_JO-kareem`: ترخيص بيانات الصوت «See URL» والمصدر غير متاح للتحقق.
  - نماذج `facebook/mms-tts-*`: CC-BY-NC-4.0 (غير تجاري).
  - باقي المرشحين: غير تجاري أو غامض أو أصوات مستنسخة.

## المطلوب لإنهائه
1. اختيار محرك/صوت عربي ترخيصه يسمح بالاستخدام التجاري وتضمين المخرجات في تطبيق (أو تزويد المقاطع جاهزة).
2. توليد 10 مقاطع (< 10 ثوانٍ لكل مقطع) بالنصوص أدناه.
3. التحويل: `afconvert -f caff -d ima4 -c 1 in.wav out.caf` (≤ 30 ثانية، تحقق بـ`afinfo`).
4. وضعها في `artifacts/majalis/ios/App/App/Sounds/` وإضافتها لهدف التطبيق (ن4)، وإدراجها في `docs/audio-rights/sound-pack.manifest.json` (approved) وفي `approvedNotificationSounds` إن لزم البوابة.
5. تسجيل اسم المحرك والصوت والترخيص في هذا الملف.

| الملف | النص |
|---|---|
| `prayer_pre_fajr.caf` | اقترب أذان الفجر |
| `prayer_pre_dhuhr.caf` | اقترب أذان الظهر |
| `prayer_pre_asr.caf` | اقترب أذان العصر |
| `prayer_pre_maghrib.caf` | اقترب أذان المغرب |
| `prayer_pre_isha.caf` | اقترب أذان العشاء |
| `prayer_now_fajr.caf` | حان الآن موعد أذان الفجر |
| `prayer_now_dhuhr.caf` | حان الآن موعد أذان الظهر |
| `prayer_now_asr.caf` | حان الآن موعد أذان العصر |
| `prayer_now_maghrib.caf` | حان الآن موعد أذان المغرب |
| `prayer_now_isha.caf` | حان الآن موعد أذان العشاء |

## الربط في الكود
`PrayerNotificationPlanner.soundName(prayer:kind:)` ← `PrayerNotificationScheduler` ← `NotificationSoundPack.phraseSounds`.
العناوين: «اقترب أذان X» (قبل الوقت، الافتراضي 10 دقائق) و«حان الآن موعد أذان X» (عند الوقت). حُذف مسار الأذان وخياراه (`adhanEnabled`/`fullAdhanChain`) كليًا.
