# قائمة اختبار الجهاز — 1.1.0 (الأحد 11 أكتوبر)

جهاز iPhone حقيقي، بناء TestFlight الموحّد. علّم كل صف بـ✅/❌ مع ملاحظة. أي ❌ في الأقسام A–C يوقف الإرسال.

## A. الإقلاع والتنقل (لا شاشة فارغة)
- [ ] A1 تثبيت نظيف ثم فتح: تظهر الرئيسية خلال 10 ثوانٍ (لا أبيض ثابت).
- [ ] A2 إقلاع بارد بعد قتل التطبيق ×3 (شبكة جيدة).
- [ ] A3 وضع الطيران ثم فتح التطبيق: تظهر شاشة خطأ/إعادة محاولة مفهومة لا أبيض.
- [ ] A4 تبديل الشبكة (واي فاي ← خلوي) أثناء التحميل.
- [ ] A5 التنقل: الرئيسية ← القرآن ← الأذكار ← المواقيت ← الدروس ← رجوع، بلا وميض أبيض.
- [ ] A6 دوران/وضع داكن/عربي RTL سليم.
- [ ] A7 فتح من الخلفية بعد ساعة: يستأنف لا يعيد أبيض.
- [ ] A8 افتح التطبيق 5 مرات وسجّل أي شاشة فارغة (الجهاز، الإصدار، الشبكة، الوقت): (1) تشغيل بارد، (2) بعد الخلفية، (3) بعد قتل التطبيق، (4) بلا شبكة، (5) بشبكة ضعيفة. عند فشل التحميل تظهر `native-load-error.html` وفيها زر «إعادة المحاولة» لا فراغ.

## B. الإشعارات الأصلية (علم native_notifications_enabled، مطفأ افتراضيًا)
- [ ] B1 افتراضيًا: لا إشعار أصلي ولا نافذة إذن عند أول تشغيل.
- [ ] B2 تفعيل تذكيرات الأذكار من الإعدادات: نافذة الإذن ثم جدولة.
- [ ] B3 الإشعار: العنوان = الذكر، النص «قال ﷺ: …»، بلا صوت أذان.
- [ ] B4 ساعات الهدوء 23:00–05:00: لا إشعار فيها.
- [ ] B5 ≤6 إشعارات يوميًا لغير الصلاة.
- [ ] B6 الصلاة تبقى على مسار الويب (لا ازدواج بين أصلي وويب).
- [ ] B7 إيقاف التذكيرات: تُمسح المجدولة.
- [ ] B8 النقر على الإشعار يفتح التطبيق على الصفحة الصحيحة.

## C. الودجات والنشاط الحي (يتطلب SunnahSharedData مسجّلًا)
- [ ] C1 إضافة كل ودجت من التسعة إلى الشاشة الرئيسية: يظهر محتوى لا فراغ.
- [ ] C2 ودجت المواقيت يطابق التطبيق (أرقام لاتينية).
- [ ] C3 ودجت الذكر/الحديث: نص موثّق فقط.
- [ ] C4 تحديث الودجت بعد تغيير الموقع/الإعداد.
- [ ] C5 Live Activity للصلاة القادمة: تبدأ وتنتهي.
- [ ] C6 ودجت قفل الشاشة (إن وُجد).
- [ ] C7 وضع داكن وحجم خط كبير.

- [ ] D1 TestFlight: يظهر التسميع مع لوحة التشخيص (ⓘ) وتُجمع الأرقام عند أول اختبار لاحق.
- [ ] D2 App Store: لا واجهة تسميع (تُتحقق ببوابة `tasmee-v2-flag-and-wiring.test.ts` وبقاء appStore=false قبل الإرسال؛ لا يمكن رؤية قناة appstore قبل النشر).
