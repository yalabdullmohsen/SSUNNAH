# اختبار الجهاز — الأحد 11 أكتوبر — بناء 1.1.0 (68)

لكل بند: افتح ← تتوقع ← إن فشل: صوّر الشاشة واكتب ما هو مذكور. لا شيء آخر مطلوب.

- **A1** احذف التطبيق وثبّته من TestFlight ثم افتحه ← تظهر الرئيسية خلال 10 ثوانٍ ← إن فشل: صوّر وكتب «A1 أبيض/خطأ + الثواني».
- **A2** اقتل التطبيق وافتحه 3 مرات ← الرئيسية في كل مرة ← إن فشل: «A2 رقم المرة الفاشلة».
- **A3** فعّل وضع الطيران وافتح التطبيق ← شاشة «تعذّر التحميل» مع زر إعادة المحاولة لا أبيض ← إن فشل: «A3 أبيض في الطيران».
- **A4** افتح التطبيق ثم بدّل واي فاي ↔ بيانات أثناء التحميل ← يكتمل التحميل ← إن فشل: «A4 توقف عند التبديل».
- **A5** تنقّل: الرئيسية ← القرآن ← الدروس ← العبادات ← المزيد ثم رجوع ← بلا وميض أبيض ولا شاشة فارغة ← إن فشل: «A5 + اسم الشاشة الفارغة».
- **A6** فعّل الوضع الداكن ثم الفاتح وأدر الجهاز ← الألوان والاتجاه (RTL) سليمان ← إن فشل: «A6 + الوضع».
- **A7** اترك التطبيق بالخلفية ساعة ثم افتحه ← يستأنف مكانه ← إن فشل: «A7 أبيض بعد الخلفية».
- **A8** افتح التطبيق 5 مرات: بارد، بعد الخلفية، بعد القتل، بلا شبكة، بشبكة ضعيفة ← لا شاشة فارغة ← إن ظهرت: صوّرها واكتب رقم المرة (1–5).

## ⓘ عند أي فشل
بعد تعافي التطبيق افتح: المزيد ← ⓘ (التشخيص) ← قسم «أسباب فشل التحميل الأخيرة». يسجّل تلقائيًا رمز السبب ووقته (بلا بيانات شخصية). صوّر هذا القسم وأرسله مع لقطة الفشل.

## القرار
كل البنود سليمة (خصوصًا A8) ← أخبر ن3 «اجتاز» فتُرسل الاثنين. أي فشل ← لا إرسال حتى الإصلاح.
