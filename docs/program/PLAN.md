# برنامج الأيام السبعة — إصدار iOS الهجين (SwiftUI + WKWebView)

- البداية: الخميس 2026-10-08 (اليوم 1) · الإصدار المستهدف: الأربعاء 2026-10-14 (اليوم 7).
- النوافذ وملكية المسارات: [OWNERS.md](OWNERS.md) · الحالة الحية: [STATUS.md](STATUS.md) · المؤجَّل والمعروف: [BACKLOG.md](BACKLOG.md).
- مسار iOS: `artifacts/majalis/ios/App/` (أدناه `ios/App/`). هدف النشر الحالي iOS 16.2.

## القرار المعماري (يُبنى عليه كل ما يلي)
- **حزمة Swift محلية** `ios/App/SunnahNative/` تحوي الهيكل الأصلي (TabView/NavigationStack) وطبقة البيانات ومضيف WKWebView، وتُبنى وتُختبر مستقلةً عن هدف التطبيق.
  - السبب: `project.pbxproj` ملف مشترك يعدّله #2742 (التسميع)؛ الحزمة تتيح العمل المتوازي دون تعارض، ثم يُربط الهدف بها في PR واحد صغير بالدور.
- التفعيل خلف مفتاح `native_shell_enabled` (افتراضيًا مُطفأ في أول بناء TestFlight، ثم يُفعَّل بعد اختبار الجهاز). الرجوع = إطفاء المفتاح دون بناء جديد للويب.
- كل شاشة لم تُحوَّل أصليًا تُعرض داخل `WebScreen` (WKWebView) بالمسار نفسه من `majlisilm.com`؛ لا تُحذف Capacitor في هذا البرنامج.

## ترتيب الدمج
1. PR التوثيق (هذا).
2. إصلاح TestFlight.
3. #2742 (النافذة 1) — أول من يمس `project.pbxproj`.
4. حزمة الهيكل → طبقة البيانات → WebScreen (لا تمس ملفات مشتركة).
5. PR الربط (`project.pbxproj` + `AppDelegate.swift`) بعد #2742 فقط.
6. ميزات اليوم 3-4 بالترتيب: المواقيت → الإشعارات → الودجت → الأذكار → القبلة.
7. تحديث `STATUS.md` في PR مستقل بعد كل دمج.

## سياسة الدمج
- كل PR: `gh pr merge --auto --squash` بعد مرور الفحوص المحلية (repo-gates، axe، visual-snapshot، layout حيث تنطبق).
- **استثناء:** أي PR يغيّر `supabase/migrations` لا يُدمج تلقائيًا ويُعلَّم «يحتاج قرارًا».
- كل دمج يمس `ios/` أو `artifacts/` يرفع بناء TestFlight تلقائيًا عبر `.github/workflows/ios-testflight-deploy.yml`؛ وهو وسيلة اختبار يوسف على الجهاز. كل PR يمس `ios/` يذكر في وصفه: «يحتاج اختبار جهاز عبر TestFlight».
- لا رفع لقاعدة الـratchet، ولا تعطيل بوابة، ولا `--admin`، ولا دفع مباشر على main.

## قاعدة الرجوع (git revert)
- الرجوع دائمًا بـ`git revert <sha>` في PR جديد بدمج تلقائي؛ لا `reset` ولا force-push على main.
- رجوع سلوكي أولًا: إطفاء `native_shell_enabled` يكفي لمعظم أعطال الهيكل دون revert.
- إن كسر الدمج البناء: revert فورًا قبل أي إصلاح، ثم يُعاد الإصلاح في PR جديد.
- revert لـPR يمس `ios/` يرفع بناء TestFlight تلقائيًا؛ يُتحقَّق منه على الجهاز.
