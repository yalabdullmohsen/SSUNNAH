# قرار 12 أكتوبر — الواجهة الأصلية إلى 1.2

القرار من المالك (9 أكتوبر 2026)، ويحلّ محلّ قالب «شحن الأصلية أم الاحتياط».

## 1. القرار
- **1.1.0 = التطبيق العادي (الويب داخل غلاف iOS)** مع الإشعارات الأصلية والودجات والتسميع.
- **الواجهة الأصلية (SwiftUI shell) تنتقل إلى 1.2** (ن7). لا عمل جديد عليها قبل 1.2 عدا الإطفاء الطارئ.
- `NativeShellGate.compiledDefault = false`؛ و`native-shell.json` للإطفاء فقط (`APP_STORE_SUBMISSION_PACK.md` §8) ولا يفعّل شيئًا.

## 2. ما يشحن في 1.1.0
| البند | الحالة |
|---|---|
| الإشعارات الأصلية (الصلاة، الأذكار) | ضمن 1.1.0 — يلزم فصلها عن علم الصدفة (انظر §4) |
| الودجات التسعة + Live Activity | ضمن 1.1.0 (يُسجَّل `SunnahSharedData` عبر #2844) |
| التسميع | ضمن 1.1.0 |
| تبويب مواقيت الصلاة الأصلي / إعدادات الإشعارات الأصلية | 1.2 |
| القبلة الأصلية | بعد الإطلاق (قرار مثبّت) |

## 3. قرارات مثبّتة مرافقة
- الأرقام لاتينية (`ar@numbers=latn`، والعدّاد `en_US_POSIX`).
- نص الحقوق: «الحقوق غير محفوظة — لوجه الله».
- الفئة Education والثانوية Reference؛ المسابقات = Yes (Infrequent/Mild)؛ التشفير Exempt؛ النطاق ssunnah.com.
- نص الصحيحين بإسناد في /sources؛ توسعة الأحاديث إلى 1.2.

## 4. أثر القرار
- الإشعارات الأصلية تُجدوَل حاليًا فقط حين تكون الصدفة مفعّلة (`NativeNotificationsLifecycle`)؛ مع الصدفة مطفأة لا تُجدوَل. الحل المقترح: علم مستقل للإشعارات (افتراضيه مفعّل، مع إيقاف عن بُعد).
- ملاحظات الإصدار والمراجعة في `APP_STORE_SUBMISSION_PACK.md` تُعدَّل بحسب هذا القرار.
- التجميد: لا دمج غير PR الـRC وإصلاحات حرجة بعد بناء 1.1.0 الموحّد.

## 5. تسلسل البناء (يحتاج من يوسف)
1. شروط الدخول: كل PRs الإطلاق مدموجة، main أخضر، بوابات iOS تعمل، ci:local ينجح.
2. كلمة **«شغّل»** لبناء واحد موحّد.
3. بعد Ready في TestFlight: لقطات، لصق ملاحظات المراجعة، Release = Manual، Submit، ثم Release يدويًا 14 أكتوبر.
