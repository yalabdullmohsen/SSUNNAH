# الصدفة الأصلية (SwiftUI) — ملخص القرار وملاحظات 1.2

المصدر: `DECISION_2026-10-12.md` (قرار المالك 9 أكتوبر 2026). ملخص تنفيذي لا يغيّر القرار.

## 1. القرار
- 1.1.0 = الموقع داخل غلاف iOS (Capacitor، `server.url`) + إشعارات أصلية + 9 ودجات + Live Activity + التسميع (TestFlight فقط).
- الصدفة الأصلية تنتقل إلى 1.2. `NativeShellGate.compiledDefault = false`، و`native-shell.json` للإطفاء الطارئ فقط.
- الإشعارات الأصلية مفصولة عن علم الصدفة (`NativeNotificationsGate`، مفتاح `native_notifications_enabled`، اشتراك اختياري، إيقاف عن بُعد) — #2856.
- الملحقات المحلية الستة تُسجَّل في `MainBridgeViewController` — #2844.

## 2. خارج 1.1.0
| البند | الموعد |
|---|---|
| تبويب مواقيت الصلاة الأصلي وإعدادات الإشعارات الأصلية | 1.2 |
| القبلة الأصلية | بعد الإطلاق |
| توسعة الأحاديث | 1.2 |
| التسميع في App Store (`appStore=false`) | بعد قياس حي في TestFlight |

## 3. ملاحظات 1.2
1. تفعيل الصدفة مرحليًا: علم عن بُعد أولًا، ثم `compiledDefault` بعد اجتياز جهاز حقيقي.
2. حساب المواقيت وجدولة الأذان محميان: الصدفة تستهلك مخرجات المحرك فقط.
3. كل شاشة أصلية على `design-system` (`--sn-*`) وتُتحقق فاتحًا/داكنًا وRTL.
4. الأرقام لاتينية (`ar@numbers=latn`).
5. تتطلب نسخة متجر جديدة (Swift/ويدجيت): لا تُسلَّم عبر الموقع وحده.
6. قياس التسميع الحي (ⓘ) يجمع الأرقام عند أول اختبار لاحق؛ لا لقطات قياس في 1.1.0.

## 4. التجميد
بعد بناء 1.1.0 الموحّد: لا دمج غير إصلاحات حرجة وPR الـRC؛ الباقي إلى 1.1.1/1.2.
