## القواعد الحاكمة للخطة كلها
- نفّذ المراحل بالترتيب، ولا تبدأ مرحلة قبل أن تُدمج سابقتها وتُنشر ويتطابق الإنتاج (version.json).
- حد أقصى PRين في نفس الوقت، وPR مستقل لكل هدف.
- فعّل الدمج التلقائي على كل PR فور فتحه، وانتقل للتالي دون انتظار. أصلح أي فشل أو تعارض حتى يُدمج.
- بعد كل دمج: تحقق من الإنتاج وclient_error_logs، وتراجع فورًا عند أي خطأ.
- ممنوع: رفع أي ceiling، وتعطيل أي بوابة، ومسّ نص القرآن أو الـ604 صفحة أو page mapping، وتغيير حساب المواقيت، وإنشاء عائلة tokens جديدة، وإخفاء العيوب بـ !important أو overflow.
- تُخفض الأسقف (ceilings) في نفس PR الذي يخفض الرقم، حتى لا يرجع الدين.
- حدّث docs/audit/SUNNAH_REMAINING_PROBLEMS_MASTER_COPYABLE.md في نهاية كل مرحلة بالأرقام الجديدة.
- لا توقف لسؤال المالك إلا في قرار يخصه (قاعدة بيانات الإنتاج، أو حذف محتوى يراه المستخدمون، أو المتجر).
