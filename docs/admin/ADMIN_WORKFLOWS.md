# Admin Workflows — نموذج تحريري مستهدف

## حالات المحتوى (مستهدف من Wave 2+)

`Draft` → `Needs Review` → `Ready` → `Scheduled` → `Published` → `Archived`

Wave 1 لا يغيّر مخطط قاعدة البيانات؛ يجهّز الـIA فقط.

## المراجعات (Inbox)

أولوية العرض:

1. بانتظار المراجعة  
2. معيّن لي  
3. عاجل  
4. رُاجع مؤخرًا

الإجراء الأساسي واحد لكل بطاقة؛ الباقي في overflow.

## المحتوى

مساحة واحدة لأنواع: دروس · مشايخ · فوائد · أسئلة · صفحات · مراجع  
تحرير سياقي + إفصاح تدريجي للبيانات الوصفية.

## التصنيف

شجرة أولًا: طي/فتح · ترتيب · تصفية · إحصاءات — بلا شبكة بطاقات مكررة كواجهة أساسية.

## البحث

مدخل واحد في الشريط العلوي (موجود في Admin v3 Shell) — توسيع الفهرس الإداري في موجة لاحقة.
