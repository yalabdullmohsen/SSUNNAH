# Unicode Rendering Root Cause — Admin

**تاريخ:** 2026-09-27  
**موجة:** Wave 1  
**الحالة:** مُصلَح في المصادر + مسار تطبيع مركزي

## الأعراض

ظهور تسلسلات مثل `\u0645\u0627\u0631...` حرفيًا داخل شاشات الإدارة بدل النص العربي.

## السبب الجذري

في **نص JSX** (بين الوسوم)، تسلسل `\uXXXX` **ليس** تهريب JavaScript. المحرّك يعرض الشرطة المائلة والـ`u` والأرقام كما هي.

مثال فاسد:

```tsx
<h2>\u0642\u0627\u0639\u062f\u0629 \u0627\u0644\u0645\u0639\u0631\u0641\u0629</h2>
```

صحيح:

```tsx
<h2>قاعدة المعرفة</h2>
{/* أو */}
<h2>{"\u0642\u0627\u0639\u062f\u0629"}</h2>
```

التهريب داخل **string literals** (`"\u0642"`) يُفسَّر وقت التشغيل — المشكلة كانت في JSX text nodes ومصادر admin مكتوبة بالشكل الحرفي.

طبقة ثانوية محتملة: JSON مزدوج التهريب من API (`"\\u0642..."`) — يُعالَج بمسار التطبيع.
