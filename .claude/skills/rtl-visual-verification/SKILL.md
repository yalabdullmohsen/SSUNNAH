# تحقق بصري RTL

Chromium مثبّت في بيئة السحابة وPlaywright مضبوط عليه (`PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers`): **لا تشغّل `playwright install`**؛ إن اشترط المشروع إصدارًا آخر فاستعمل `executablePath: '/opt/pw-browsers/chromium'`.

## المصفوفة الدنيا
- نافذة جوال (≈390×844) وسطح مكتب، **فاتح وداكن**، اتجاه `rtl`، وحجم خط كبير.
- شاشات الصلة: الصفحة الرئيسية، المصحف، المواقيت، الأذكار، البحث، الإعدادات.

## الخطوات
1. شغّل الخادم المحلي للتطبيق (راجع سكربتات `artifacts/majalis/package.json`).
2. التقط لقطة لكل حالة في المصفوفة، ثم افحصها بالعين (Read على الصورة): قص النص، تراكب، أزرار خارج الشاشة، أرقام غير متسقة، تباين ضعيف.
3. شغّل بوابات المشروع المحلية قبل الدفع: axe وvisual-snapshot وlayout (`pnpm --filter @workspace/majalis run test:visual` وما يخص ملفاتك؛ و`pnpm run ci:local`). لا تعطّل بوابة ولا ترفع سقفًا.
4. للمصحف: لا تتحقق بصريًا فقط؛ طابق تقارير التكافؤ (`mushaf-pitfalls`).

اللقطات أدلة مؤقتة: لا تُدخلها في PR إلا إن كانت جزءًا من بوابة مطلوبة. ولا تدّعِ أن الواجهة صحيحة على iPhone من لقطة Chromium.
