# فشل CI: جذري لا ترقيع

1. اقرأ سجل الفشل الفعلي (لا تخمّن) وحدد الطبقة: بوابة سقف، اختبار، بناء، بيئة.
2. أعد إنتاجه محليًا بـ`pnpm run ci:local` (و`-- --full` لمطابقة CI).
3. أصلح **السبب** لا العَرَض: ممنوع تعطيل بوابة أو رفع سقف أو إخفاء الخلل (`.claude/rules/design-system.md`).
4. إن تكرر هذا النوع: أضف حارسًا/فحصًا قبل الدفع (hook في `scripts/git-hooks`، أو توسيع `scripts/ci-local.mjs`) بحيث يظهر الخطأ محليًا، ووثّق السبب في PR.
5. حتى 10 دورات إصلاح ثم وثّق وانتقل (`CLAUDE.md`).
6. الدمج التلقائي معطّل؟ راجع `.github/workflows/auto-merge-to-main.yml` وسياسة safe-auto-merge قبل أي دفع يدوي لـmain.
7. اذكر في التقرير: السبب الجذري، ما منع تكراره، وما بقي.
