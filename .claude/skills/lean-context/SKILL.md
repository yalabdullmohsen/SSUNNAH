# عمل خفيف السياق

1. **الفهرس أولًا**: `docs/REPO_INDEX.md` ثم مهارة `graphify` للأسئلة البنيوية. لا تمسح المستودع (أكثر من 11 ألف ملف).
2. **قراءة موجَّهة**: `grep` بنمط ضيّق ثم اقرأ المقطع (offset/limit) لا الملف كاملًا. لا تقرأ `reports/*` و`docs/audit/*` و`test-results/*` إلا إن كانت هي المطلوب.
3. **المسار الإلزامي** (`docs/AGENT_THROUGHPUT.md`): Targeted Read ← Plan ← Patch ← Focused Test ← Full Verify. اختبر الموجَّه أولًا، والكامل مرة واحدة قبل الدفع.
4. **المخرجات الطويلة**: وجّهها لملف مؤقت وأظهر `tail`/`grep` فقط (مثل أوامر git clone وbuild وtest).
5. **التوازي**: الاستعلامات المستقلة في رسالة واحدة. لا تفتح وكيلًا فرعيًا لشيء تعرف هدفه.
6. **لا تعد القراءة**: لا تقرأ ملفًا عدّلته للتو، ولا تلخّص خطواتك في الرد.
7. **التقارير المولّدة** لا تدخل PR إلا عمدًا (تطلق وسوم danger-path).
