# مراجعة قبل الدمج

المالك يدمج بلا مراجعة يدوية، فأنت خط الدفاع الأخير. اقرأ `git diff origin/main...HEAD` كمراجع غريب وافحص:

1. **النطاق**: هل كل سطر مطلوب؟ لا تنظيف جانبي، لا ملفات مولّدة (`docs/audit/*` و`reports/*` إلا عمدًا)، ≤40 ملفًا و≤400 سطر محذوف.
2. **المحتوى المحمي**: لا مساس بنص القرآن/ترقيمه/الصفحات، ولا بحساب المواقيت (`.claude/rules/protected-content.md`). أي محتوى شرعي جديد مرّ بـ`sharia-content`.
3. **الأمان**: لا أسرار/مفاتيح/شهادات في الـdiff، RLS لم يضعف، لا SQL إنتاج (`security-public-repo`).
4. **الهوية**: لا hex/px/خط حرفي خارج `design-system`، ولا نظام أزرار/بطاقات جديد، ولا إيموجي في الواجهة.
5. **الديون**: لا زيادة في أي عدّاد؛ السقوف لم تُرفع (`release-1-1-0`).
6. **الاختبارات**: هل اختبر التغيير السلوك فعلًا (لا مصدرًا مثبّتًا لأسماء مكوّنات)؟ شغّلت `pnpm run ci:local`؟
7. **الحالات الحدّية**: RTL، فاتح/داكن، أصغر جهاز، بلا شبكة، قيم فارغة.
8. **نص الـcommit والـPR**: عربي، يذكر السبب لا الملفات، والتقرير يطابق ما حدث فعلًا.

وجدت مشكلة؟ أصلحها قبل الدفع وسجّلها في التقرير. لا تدفع وأنت تشك.
