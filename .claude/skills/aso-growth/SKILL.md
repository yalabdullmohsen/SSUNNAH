# ظهور التطبيق ونموّه

- الأساس: `store/metadata-ar.md` و`docs/store-release/STORE_ASSET_MANIFEST.md`. اكتب بيانات كل لغة بأصالة لا بترجمة حرفية (راجع `i18n-global`).
- العنوان والعنوان الفرعي: اسم «سُنّة» + وصف وظيفي؛ الكلمات المفتاحية 100 حرف بلا تكرار لما في العنوان ولا فواصل زائدة.
- اللقطات: أول ثلاث تحمل القيمة الأهم (المصحف، المواقيت، التسميع) بالخط والهوية الرسمية، فاتحة وداكنة.
- «ما الجديد»: صادق ومحدد لكل إصدار (مثل 1.1.0).
- لا ادعاءات غير محققة (أرقام تحميل، «الأول»، «الأفضل»)، ولا مقارنة باسم تطبيق آخر.
- التقييمات: طلب التقييم مرة بعد لحظة نجاح حقيقية (ختم ورد مثلًا) عبر واجهة النظام، لا ضغطًا متكررًا.
- القياس: مؤشرات المتجر الرسمية فقط؛ لا تتبع يخرق إفصاح الخصوصية.
