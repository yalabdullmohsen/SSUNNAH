# البحث العربي

- أداة القياس: `scripts/check-search-quality.js`؛ شغّلها قبل وبعد وأرفق الفرق.
- التطبيع: إزالة التشكيل والتطويل، توحيد الألف (أ إ آ ا)، والياء/الألف المقصورة، والتاء المربوطة/الهاء، مع الإبقاء على النص الأصلي للعرض. لا تعدّل النص المخزَّن (القرآن محمي).
- الفهارس المولَّدة (`public/data/search/shards/`) لا تُتتبَّع؛ تُولَّد عبر `generate:search-index` (الـindex والـmanifest فقط متتبَّعان).
- حالات اختبار دائمة: كلمة مشكولة/غير مشكولة، آية بجزء من الكلمة، اسم سورة بكتابتين، رقم آية، حديث بكلمة غير متصلة.
- لا نتائج «ذات صلة» عشوائية: قرار المالك حذف قسم الاقتراحات غير المرتبطة.
