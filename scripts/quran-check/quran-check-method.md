# طريقة فحص اقتباسات القرآن (ن8) — `q-scan.mjs` + `lib.mjs`

## أمر التشغيل (من جذر المستودع، Node 18+، بلا تثبيت حزم)
```bash
# مجلد بيانات محدد (أو ملف، أو عدة مسارات):
node scripts/quran-check/q-scan.mjs ios-native/Data

# بلا مسار: مجلدات محتوى الويب الافتراضية (artifacts/majalis/{public/data,content,src/...,supabase} و supabase/)
node scripts/quran-check/q-scan.mjs

# حفظ النتيجة JSON أيضًا (الملف الوحيد الذي يُكتب):
node scripts/quran-check/q-scan.mjs ios-native/Data --json /tmp/quran-findings.json
```
- المخرَج على الشاشة قائمتان فقط: **«نص ليس في القرآن»** و**«عزو خاطئ»**، لكل بند الملف:السطر [المعرّف] والنص والمرجع المكتوب والموضع الأقرب/الفعلي، ثم سطر إجمالي.
- لا يعدّل أي ملف. المرجع: Tanzil في `artifacts/majalis/public/data/quran` (يُغيَّر الجذر بـ `QURAN_CHECK_ROOT=<مجلد فيه public/data/quran>`).
- الامتدادات المفحوصة: json, ts, tsx, sql, md, csv, swift, strings, txt.

## المرجع
نص Tanzil العثماني المقفول في المستودع: `artifacts/majalis/public/data/quran/surah-001..114.json`. تُضمّ كل الآيات في نص واحد متصل (بعد التطبيع tier2)، مع خريطة من الموضع إلى السورة والآية.

## الصيغ المفحوصة (في كل نصوص JSON/TS/SQL/MD، ما عدا مجلدات القرآن والحديث والبحث والنسخ الاحتياطية والاختبارات)
1. `﴿…﴾`: كل ما بين القوسين المزخرفين.
2. `{…}`: الأقواس المعقوفة التي فيها عربية، ويُستبعد ما يشبه الكود (`;` أو `=` أو `=>` أو `return`).
3. **كائنات الأدلة:** `{"type":"quran|ayah|آية|قرآن", "ref":"…", "text":"…"}`. يُؤخذ `ref` بصيغة `س:آ` مرجعًا مكتوبًا إن وُجد.
4. **«قال تعالى»** وأخواتها (تعالى، عز وجل، جل وعلا، سبحانه، مع «في سورة كذا» اختياريًا)، متبوعة بنص بين «» أو "" أو () أو [].

## تجهيز الاقتباس
- تُحذف أرقام الآيات المضمّنة `(12)` و`۝12`.
- يُقسَّم الاقتباس عند `...` و`…` و`—` و` - `، ويُفحص كل مقطع على حدة.
- يُتجاهل المقطع الذي يقل عن 6 حروف بعد التطبيع، لقصره عن الحكم.

## مطابقة الرسم والهمز (التطبيع)
- **tier1 ‏`sk1`:**
  - يحذف التشكيل وعلامات الوقف والتطويل والمحارف الخفية (RLM/BOM…).
  - يوحّد الهمزات: آ/أ/إ/ٱ → ا، ؤ → و، ئ → ي.
  - يوحّد ى → ي، ة → ت.
  - يحوّل الألف الخنجرية وصلة الرسم: وٰ/ىٰ → ا، ۦ → ي، ۥ → و.
  - يُبقي الحروف فقط بلا فراغات.
  - يوحّد فروق الرسم العثماني المعروفة: الليل/اليل، أن لا/ألا، من ما/مما، اللاتي/التي، اللائي/الي، بصط/بسط، مصيطر/مسيطر.
- **tier2 ‏`sk2`:** هو `sk1` مع حذف حروف المد والهمز (ا و ي ء)، فيتجاوز فروق الإملائي والعثماني، مثل الصلوة/الصلاة والكتب/الكتاب.
- **المطابقة:** المقطع بعد tier2 يجب أن يوجد سلسلةً متصلة (substring) في نص المصحف المتصل؛ لا تشابه تقريبي ولا مطابقة بالمعنى.

## الحكم
- **«نص منسوب للقرآن ليس فيه» (حرج):** أي مقطع لا يوجد متصلًا. يُقترح أقرب موضع (أطول بادئة أو LCS بنسبة 0.45 فأكثر)، ويُستخرج النص الصحيح حرفيًا من Tanzil بواسطة `align.mjs`.
- **«عزو آية خاطئ» (حرج):** النص صحيح لكن المرجع المكتوب بعده (سورة ورقم، بالأرقام اللاتينية أو الهندية) لا يحتوي النص ضمن نطاق ±1 آية.
- **سليم:** النص موجود، والمرجع إن وُجد يطابقه.

## أدوات مساعدة (اختيارية)
